# mnemosyne-socials

Gerenciador de links sociais: guarda em SQLite o que queremos ver, o que já vimos e quando.

Requer Node 26 (`.node-version`, ou `nix develop`).

```sh
npm install
npm run check
npm start
```

Contexto, arquitetura e convenções estão no [AGENTS.md](AGENTS.md). Suporte por ferramenta de agente está em [docs/harnesses.md](docs/harnesses.md).
